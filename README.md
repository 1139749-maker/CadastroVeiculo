O trabalho tem o objetivo de desenvolver um sistema para o cadastro e gerenciamento de veículos, permitindo o registro de informações como marca, modelo, ano de fabricação e placa. Possibilitando o armazenamento dos dados em memória, bem como a listagem completa dos veículos e a consulta ao pesquisar a partir da placa.

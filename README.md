O trabalho tem o objetivo de Desenvolver um sistema de Cadastro de Veículos utilizando os conceitos de Programação Orientada a Objetos (POO) em Java. Isso possibilita o gerenciamento de veículos e permite o registro de informações como marca, modelo, ano de fabricação e placa. Além de armazenar os dados em memória, listar e consultar os veículos ao pesquisar a partir da placa.
